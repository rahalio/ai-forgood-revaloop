# Revaloop — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Grading and triage technician

- As a grading technician, I want the system to propose a cosmetic and functional grade from captured images and diagnostics, so that my throughput is not limited by writing up condition notes by hand.
- As a grading technician, I want cosmetic features of the model — logos, speaker grilles, camera rings — distinguished from genuine damage, so that normal design elements stop being recorded as defects.
- As a grading technician, I want to challenge a proposed grade and have the challenge resolved with evidence, so that a wrong score does not silently set the price of a unit I can see is better than that.
- As a grading technician, I want a unit that fails data erasure or battery-safety checks to be routed away from resale automatically, so that I cannot accidentally release a device that should never be offered to a customer.

### Circular operations planner

- As a circular operations planner, I want each incoming batch split into next-cycle routes with expected net recovery per route, so that I can commit capacity to refurbishment or harvesting instead of clearing volume to whichever broker answers first.
- As a circular operations planner, I want reverse-logistics lanes ranked on landed cost with illegal movements excluded, so that consolidation decisions do not create a permit problem downstream.
- As a circular operations planner, I want to see how much recovery was lost to the design of a particular model, so that the next product programme receives an evidenced list of the disassembly and part-commonality changes worth funding.

### Remanufacturing and warranty engineer

- As a remanufacturing engineer, I want predicted yield for each harvestable part on an incoming batch, so that I release jobs that will actually produce sellable components rather than scrap with labour attached.
- As a warranty engineer, I want a predicted failure risk and a corresponding reserve on every harvested part, so that a cheap component does not become an expensive field return.
- As a warranty engineer, I want parts and units blocked from reuse when restricted-substance or safety status cannot be confirmed, so that compliance failure is impossible rather than unlikely.

### Residual pricing analyst

- As a pricing analyst, I want residual-value forecasts per model, grade and market with a confidence band, so that trade-in offers reflect where the secondary market is rather than where list prices were last quarter.
- As a pricing analyst, I want the system to reject an offer table whose expected loss exceeds the approved risk budget, so that a promotional trade-in campaign cannot quietly subsidise itself out of the aftermarket P&L.

### Compliance and EPR administrator

- As a compliance analyst, I want EPR declarations and eco-modulation drivers built from the operational record, so that filings are defensible and fee changes traceable to specific design or process decisions.
- As a compliance analyst, I want recycled-content and reuse claims blocked when the underlying flow cannot be verified, so that marketing cannot publish a number the physical record will not support.
- As a platform administrator, I want bill-of-materials fields, cost data and imagery exposed to each partner only under a recorded agreement, and every disposition reproducible with its model version and price inputs, so that both supplier confidentiality and audit reconstruction hold at the same time.
